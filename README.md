# Django Blog Management System

## Overview

A Django-based blog application where users can read blog posts, comment on articles, search for content, and discover related posts.

## Key Features

-  **Blog Management:** Create, view, and manage blog posts through Django Admin.
-  **Comment System:** Allow readers to comment on blog posts.
-  **Pagination:** Browse blog posts page by page.
-  **Email Sharing:** Share blog posts via email.
-  **Tagging System:** Organize and filter posts using `django-taggit`.
-  **Similar Posts:** Recommend related articles based on tags.
-  **Search System:** Find blog posts using keywords.
-  **SEO & Feeds:** Generate XML sitemaps and RSS feeds.
-  **PostgreSQL & Docker:** Run and manage the database using Docker.

##  Technologies Used

- Python & Django
- PostgreSQL
- Docker
- django-taggit
- HTML & CSS
- Git & GitHub
