# Django Blog Management System

## Overview

A feature-rich blog management system built with Django. It allows users to explore blog posts, leave comments, search for content, share articles via email, and discover related posts. The project also includes SEO-friendly features and PostgreSQL database integration using Docker.

##  Key Features

### Blog Management
- Create and manage blog posts.
- Display a list of published posts.
- View detailed pages for individual blog posts.
- Manage blog content through the Django Admin Panel.

###  Comment System
- Allow readers to comment on blog posts.
- Display comments associated with each post.
- Manage comments through the Django Admin Panel.

### Pagination & Email Sharing
- Navigate through blog posts using pagination.
- Share blog posts via email using a dedicated form.
- Validate email form submissions.

###  Tagging System
- Organize blog posts using `django-taggit`.
- Filter posts by tags.
- Navigate between related posts through tags.

###  Similar Post Recommendations
- Recommend related blog posts based on shared tags.
- Help readers discover relevant content.

###  Search System
- Search for blog posts and content using keywords.
- Quickly find relevant articles.

###  SEO & Feeds
- **XML Sitemap:** Automatically generate a sitemap for search engines.
- **RSS Feed:** Allow readers to subscribe to updates from new blog posts.
- **SEO-Friendly URLs:** Use descriptive URLs for blog posts.

### Database & Docker
- **PostgreSQL:** Use PostgreSQL as the relational database.
- **Docker:** Run and manage PostgreSQL inside a Docker container.
- **Database Integration:** Configure Django to connect to PostgreSQL.
